Windows utility

See the heat before it becomes a problem.

TempGuard is a lightweight system-tray utility that surfaces the hottest current CPU or GPU temperature, explains the thermal state with clear color cues, and helps identify high-CPU processes.

Core capabilities

Clear signals, useful context.

The hottest trustworthy sensor drives the tray color so an average cannot hide a hotspot.

01Monitor

Live thermal status

Shows the hottest current CPU or GPU reading in the tray, with configurable green, orange, and red thresholds.

02Diagnose

CPU load visibility

Lists processes by recent CPU use every two seconds, alongside process ID, memory use, and window title when available.

03Act carefully

Guarded task control

Allows confirmed task termination while protecting TempGuard, other user sessions, and known critical Windows processes.

Reliable behavior

Designed for useful, low-noise monitoring.

TempGuard focuses on practical safeguards around sensor quality, notifications, and optional system integration.

Engineering details

  • Two-degree threshold hysteresis reduces repeated notifications near a boundary
  • Gray status clearly indicates that no trustworthy sensor reading is available
  • Optional PawnIO sensor support is downloaded only after confirmation and checked against a pinned SHA-256 hash
  • Per-user startup avoids elevated scheduled tasks and UAC bypasses

Privacy & safety

Local by default, honest about limits.

Temperature and process-usage data remain on the computer. The running application makes no background network requests; a network request happens only when the user explicitly chooses to install optional sensor support.

◉

No telemetry

No usage analytics or remote monitoring.

✓

Explicit installation

Optional sensor support requires confirmation.

△

Advisory tool

It does not replace hardware thermal protection.

TempGuard cannot universally stop charging, change fan curves, or guarantee shutdown prevention. Persistent overheating should be inspected professionally.
